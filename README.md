# Обход для чайников

Программа для Windows, которая отправляет через ваш сервер только то, что не открывается напрямую, а всё остальное
оставляет как есть. Внутри — встроенное ядро [sing-box](https://github.com/SagerNet/sing-box) (TUN), интерфейс на
WebView2 (`ui.html`, `mini.html`), всё остальное — Go.

Возможности: несколько путей к серверу с автоматическим выбором (в том числе через ретрансляторы), игровой режим,
блокировка рекламы со счётчиком, «радар» блокировок, проверка сайта и журнал связи, автообновление с проверкой
подписи, мини-панель в трее.

## Как устроено ядро

sing-box подключён как Go-библиотека и собирается в тот же exe. Туннель работает во втором экземпляре программы,
запущенном с ключом `-core` (`corerun.go`): паника в ядре не роняет окно, программа видит падение и перезапускает
туннель. Остановка — закрытием stdin ядра (мягкое закрытие TUN), через 3 секунды — принудительно. Статистику и задержки
окно берёт из clash API ядра на 127.0.0.1.

## Сборка

Нужен Go 1.25.5+. Теги ядра лежат в `CORE_TAGS` — без них сборка намеренно не проходит.

```
GOOS=windows GOARCH=amd64 go build -tags "$(cat CORE_TAGS)" -trimpath \
  -ldflags "-s -w -H=windowsgui -checklinkname=0 -X main.appVersion=6.3.0" -o app.exe .
```

Установщик (NSIS, мастер на русском; нужен `apt install nsis`):

```
tools/setup/build.sh 6.3.0 app.exe out/
```

Тихая установка: `Obhod-Setup-vX.exe /S`, тихое удаление (настройки остаются): `uninstall.exe /S`.

## Тесты

```
go test -tags "$(cat CORE_TAGS)" -ldflags=-checklinkname=0 ./...
GOOS=windows go vet -tags "$(cat CORE_TAGS)" .
```

`TestEmbeddedCoreProcess` собирает программу и проверяет ядро вживую (запуск, порт, мягкая остановка); `-short` его пропускает.

## Обновления

Архив `Obhod-vX.zip` подписывается ключом: `go run ./tools/release sign Obhod-vX.zip X signing.key`.
Публичный ключ зашит в `update.go`, приватный в репозитории не хранится. Программа ставит только архивы с верной подписью.
