# Обход для чайников 6.1.1
- **Чат с поддержкой в «Помощи».** Пишешь прямо из программы, отчёт о работе прикладывается одной галочкой (без паролей и ключей). Ответ администратора приходит в окно и в Telegram, о новом ответе напомнит уведомление Windows. Работает после входа через Telegram.
- **«Связь за сутки» в «Помощи».** Раз в минуту программа сама проверяет каждый путь к серверу (напрямую, через Питер, через Стокгольм) и обычный интернет. Полоски показывают, когда и что не работало; журнал прикладывается к отчёту.
- «Несколько путей» теперь работают и для копий входа на другом порту (например «vless-2083 (443)»): для них тоже находятся пути через ретрансляторы. В «Подключении» такие копии показаны одной карточкой с меткой «порт 443».
