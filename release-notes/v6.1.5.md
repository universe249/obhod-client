# Обход для чайников 6.1.5
- Новый установщик: обычный мастер на русском. Можно выбрать папку, ярлык на рабочем столе и автозапуск с Windows. Если программа уже стоит, она обновится в ту же папку, а настройки, серверы и подписка сохранятся. Установщик стал вдвое меньше: 26 МБ вместо 55.
- Нормальное удаление через «Установка и удаление программ». Можно оставить или удалить настройки. Автозапуск теперь удаляется вместе с программой (раньше задача могла остаться).
- Программа меньше нагружает компьютер, пока открыто окно. Раньше она каждые полторы секунды запускала системную утилиту, чтобы проверить автозапуск, а для поиска игр и мешающих программ — список процессов через tasklist. Теперь автозапуск проверяется раз в минуту, а процессы читаются напрямую у Windows.
- При большом числе соединений окно обновляется вдвое быстрее.
- Сама программа стала меньше: 9,5 МБ вместо 13.
