# Обход для чайников 6.0.19
- Исправлен пинг серверов при включённом VPN: раньше показывалось 1–3 мс (замер замыкался внутри самой программы), а неработающий сервер выглядел живым. Теперь проверка идёт напрямую через сетевой адаптер, как настоящее соединение.

- В карточке подписки сервиса — кнопка «Продлить или докупить трафик» в боте.
