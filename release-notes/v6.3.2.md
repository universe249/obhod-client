# Обход для чайников 6.3.2
- Исправлено: в 6.3.0 и 6.3.1 не открывались сайты, которые идут напрямую (ошибка «сервер не найден», Windows писала «Без доступа к Интернету»). Защита от утечек DNS в Windows узнаёт ядро по пути к файлу, а путь с русскими буквами («Обход для чайников.exe») она не распознавала и блокировала запросы самого ядра. Теперь ядро запускается из `data\obhod-core.exe` — это ссылка на ту же программу, место на диске она не занимает. Если папка программы называется по-русски, ссылка лежит в `C:\ProgramData\Obhod`.
