# Обход для чайников 6.3.0
- Ядро sing-box (1.14.4) встроено в саму программу. Отдельного `sing-box.exe` больше нет: программа — один файл, установщик и обновления заметно меньше. Старый `sing-box.exe` из папки `data` удалится сам, когда станет не нужен для отката.
- Ядро работает отдельным процессом этой же программы: если оно упадёт, окно останется открытым и само перезапустит туннель.
- Туннель выключается мягко: ядро успевает убрать сетевой адаптер и маршруты, а не обрывается.
- Кнопка «Скачать / обновить sing-box» убрана — ядро обновляется вместе с программой.
- Код программы открыт под лицензией GPL-3.0.
